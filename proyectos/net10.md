# Reglas de este repositorio (.NET 10)

## Stack y operaciones permitidas
- Proyecto en .NET 10. Usar Git, PowerShell y el SDK estable de .NET 10.
- Se permite ejecutar dotnet restore, build, test y publish dentro del repositorio. Publish genera artefactos locales; no implica desplegar.
- No cambiar el TargetFramework de ningún proyecto sin autorización.

## Restricciones adicionales
- No incorporar Node.js, npm, Docker ni servicios externos sin autorización del responsable técnico.
- Crear ramas, commits o interactuar con remotos solo con autorización explícita del responsable técnico.
